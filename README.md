# Lung Disease Detection System

An AI-based lung disease prediction system developed using Deep Learning and Computer Vision techniques.

The project analyzes chest X-ray images and classifies them into classes such as Normal, Nodules, Pneumonia, Tuberculosis, and Unknown.

The model is built using the EfficientNetV2-B3 transfer learning architecture with TensorFlow and Keras for high accuracy and faster training.

Image preprocessing, data augmentation, batch normalization, dropout, early stopping, and L2 regularization techniques are used to improve model performance and reduce overfitting.

For better interpretability and explanation of predictions for doctors, the LIME (Local Interpretable Model-Agnostic Explanations) technique is integrated into the system.
